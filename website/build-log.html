How this log is derived

Every entry below is a commit subject and date exactly as they appear in the git history of the main branch — the output of git log --oneline --date=short --pretty='%ad %s' as of 2026-10-18. None of the entries are rewritten, summarised or invented; the only editorial text is the group headings and the short context paragraph under each one.

Groups follow the milestones named in the design records under docs/design: the quality overhaul, the Omarchy-first TUI, TUI/GUI parity, the Quickshell patchbay and the stereo pipeline. The two earlier groups cover the foundation and the client work that predate those records, and one group covers the contributor reorganisation between them. Milestone one-liners come from the merge commit titles and CHANGELOG.md.

Work that is still an open pull request is listed at the end under In review. None of it has landed on main. This page is a static snapshot dated 2026-10-18 and is meant to be extended as the project moves.

Stereo pipeline

2026-10-17 → 2026-10-18 · PR #10

Stereo end to end: a channel-aware resampler and EQ (each channel keeps its own filter state), frame-safe stereo helpers for capture, CD and bridge, and stereo to every speaker stream. Mono destinations get an (L+R)/2 downmix; destinations with more than two channels get their extra channels silent. In review

Opened 2026-10-18 · not merged

Pull requests that are open right now. Nothing here has landed on main; each line is the PR's own title and commit subject.

  1. 2026-10-18 feat(core): dither L16 quantization and round instead of truncating — PR #11, in review. First half of the cleaner-audio roadmap item: the L16 encode rounds to nearest with TPDF dither instead of truncating toward zero.
  2. 2026-10-18 One-line Omarchy installer; AUR recipes follow the submission guidelines (revives #6) — PR #12, in review. Turns packaging/omarchy/install.sh into a one-line installer of the release's prebuilt binaries with pinned checksums, and brings the AUR recipes in line with the submission guidelines.
  3. 2026-10-18 docs: roadmap action plan with dependencies — PR #13, in review. The action plan behind the roadmap items on the site.
  4. 2026-10-18 Project website and living build log under website/ — PR #14, in review. This site: a static, dependency-free build of the feature list, the architecture and the log you are reading.
  5. 2026-10-18 quickshell: drag-only patchbay cables, whole-curve cable delete, media widget and toasts — PR #15, in review. Connecting becomes a gesture only: the click-to-connect menu is gone, one cable-drag path remains and a test pins it there. Right-clicking anywhere on a cable removes it. Adds the Omarchy media widget and coalesced notifications.
  6. 2026-10-18 Shared playback timeline + cross-protocol sync foundation — PR #16, in review. The foundation of mixed-protocol playback: every audio chunk now carries a frame index and capture time, outputs can be grouped onto one presentation epoch, each holds a delay line, and drift is steered through a variable-ratio resampler. Per-output latency trim and sync status are exposed. Every latency figure is a documented default, not a measurement.
  7. 2026-10-18 Stereo level meter, DSP quality profiles, sync-aware Sonos recovery — PR #17, in review. The level meter reports left and right separately instead of one combined reading. Three resampler quality profiles, chosen by a benchmark that measures each one on the machine it is running on. Sonos stall recovery no longer restarts playback at arbitrary times when an output is in a sync group.
  8. 2026-10-18 Stereo meters, DSP quality selection and sync controls in every client — PR #18, in review. The terminal UI, the desktop window and the phone remote all show the two meters, the quality profile, and a per-output latency trim with its sync state.
  9. 2026-10-18 D-Bus MPRIS bridge — PR #19, in review. External media controls can see and drive on-air. The bridge holds no bus connection at all while nothing is playing, so a machine with no disc and no active output shows no phantom player.
  10. 2026-10-18 Tests for the desktop installer's decision and failure paths — PR #20, in review. The desktop installer was only checked for shell syntax. It is now driven for real, with the toolchain mocked and no network or root. Fixes a defect found along the way: a failed install was reported as success.
  11. 2026-10-18 First-use automatic tuning and audio-path allocation guardrails — PR #21, in review. A new computer runs the audio check once by itself and configures its capture buffer and resampler from the result, without overwriting anything the user already chose. The audio path's per-chunk allocation behaviour is now a measured number rather than a claim.
  12. 2026-10-18 Sync groups: create them over the API, form them in every client — PR #22, in review. Several speakers can be put into a group and started together at one instant. This is what makes the timeline above reachable by a user rather than only by the code.
