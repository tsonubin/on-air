Setup & support

Setup & support.

Start with the desktop companion

Install on-air on your computer using the installation guide. Keep the companion running while using the phone remote. The desktop captures and streams audio; the phone app controls it.

Pair your iPhone or iPad

  1. Connect the phone and desktop to the same trusted local network.
  2. Open on-air remote and allow local network access when iOS asks.
  3. Choose your desktop. If it is not found, tap “Set up manually” and enter its address, such as 192.168.1.20. The default port is 47990.
  4. Enter the six-digit PIN shown by the desktop companion. For the terminal client, on-air status shows the pairing information.

No desktop found?

Check that the companion is running, both devices share the same network, and local network access is enabled for on-air remote in iOS Settings. Guest Wi-Fi, client isolation, or VPN routing may prevent local connections. Try entering the desktop’s address manually. The companion uses TCP port 47990 for control; allow it on your trusted LAN in the computer’s firewall.

Paired, but no sound?

Choose an available input and speaker. Check that the desktop service is enabled and the source is producing audio. on-air remote does not play phone audio. The available speakers and actions come from the desktop companion.

AirPlay on a Mac

macOS AirPlay output is selected through the system route picker on the Mac. The remote cannot drive that picker or select a Mac’s AirPlay route. Sonos and Bluetooth controls remain available through the companion.

Changed desktop address?

Open Connection, use “Forget desktop,” and pair again at the new address. A temporary network failure does not require forgetting the desktop; try Refresh first.

Report a problem

Open an issue on GitHub with your phone OS, desktop OS, app version, and the action that failed. Include the visible error message. Remove pairing tokens, PINs, and private details from logs or screenshots.
